# Twin Wedding Digital Invitation Card 💍✨

A luxury, interactive royal burgundy & gold digital wedding invitation created for the twin sisters **Salmabee** and **Rahmabee**, celebrating their joyous marriages with **Muhammed Ajnas** and **Shahbaz Muhammed**.

---

## 🌟 Key Highlights & Features

- ✉️ **Royal 3D Envelope Unfold**:
  - Closed royal lace envelope with a 3D golden wax seal.
  - Majestic 5.8s slow unfolding animation revealing *"YOU'RE CORDIALLY INVITED"* and Arabic Bismillah calligraphy.
  - Authentic acoustic wax seal break chime effect.

- ✒️ **Slow Calligraphy Handwriting Animation**:
  - Bride & groom names gracefully handwritten in royal cursive script with a glowing golden pen nib leading each stroke.
  - Highlighting both twin unions with noble serif typography.

- 🎨 **Artistic Twin Couples Artwork**:
  - Cinematic two-side gliding entrance onto parchment card with traditional Arabic calligraphy.

- 📜 **Ceremony Details & Event Schedule**:
  - Host parents: **Mr. Abdul Rahman & Mrs. Zeenath Rahman** (*Puthukkudy, P.O. Vakayad, Naduvannur*).
  - Split cards detailing each couple's lineage, Quranic blessing (*Surah Ar-Rum 30:21*), and event timings.
  - **Live Countdown Timer** ticking down to **07 November 2026, 5:00 PM IST**.

- 🗺️ **Full-Screen Mobile Venue Guide**:
  - Edge-to-edge Google Maps integration (`flex: 1` fill) with one-click **Get Directions** and **Copy Address**.
  - **Replay from Beginning** button to seamlessly re-watch the presentation.

- 🎵 **Background Music ("Bi Saraha" by Abeer Nehme)**:
  - The viral Instagram & YouTube romantic Arabic love song **"Bi Saraha" (بصراحة) by Abeer Nehme**.
  - Dual audio format support (`.m4a` and `.mp3`).
  - Seamless mobile autoplay gesture handling with animated golden glowing music indicator (`🔊` / `🔇`).

## 🚀 How to Run Locally

You can run the invitation card using any standard HTTP server:

```bash
# Clone the repository
git clone https://github.com/adilafarhana-dev/twinwedding.git
cd twinwedding

# Start a local Python server
python -m http.server 8080
```

Open your browser at:
`http://localhost:8080/index.html`

## 🌐 Publish to GitHub Pages (Free Live URL)

To share this invitation online with family and friends:
1. Go to your repository on GitHub: **`https://github.com/adilafarhana-dev/twinwedding`**
2. Click on **Settings** ➔ **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, your wedding invitation will be live at:
   **`https://adilafarhana-dev.github.io/twinwedding/`**
